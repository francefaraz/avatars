# Avatar Collection

This directory contains a collection of avatar images used in the BizOwl project.

## 📦 Source

All avatars in this collection are sourced from the [alohe/avatars](https://github.com/alohe/avatars) repository and are served via jsDelivr CDN.

**Repository:** https://github.com/alohe/avatars  
**CDN:** https://cdn.jsdelivr.net/gh/alohe/avatars/png/

## 🎨 Avatar Categories

This collection includes avatars from the following categories:

- **Vibrent** (27 avatars) - Vibrant, colorful avatar styles
- **3D** (5 avatars) - Three-dimensional avatar designs
- **Bluey** (10 avatars) - Blue-themed avatar collection
- **Memo** (35 avatars) - Memo-style avatar designs
- **Notion** (15 avatars) - Notion-inspired avatars
- **Teams** (9 avatars) - Team-oriented avatar styles
- **Toon** (10 avatars) - Cartoon-style avatars
- **Upstream** (22 avatars) - Upstream-themed avatars

**Total:** 133 unique avatar images
